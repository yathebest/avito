# Определение ориентации текста

Решение выдаёт вероятность `p_180` для 20 000 текстовых кропов. Метрика — `1 − Brier Score`.

## Запуск

Нужны Docker и тестовые данные. Положите распакованный набор в `test_data/`: файл `sample_submission.csv` и изображения `test/images/*.png`. Вместо этого можно положить `test.zip` в корень проекта. Веса модели уже в репозитории.

Из корня проекта выполните в PowerShell:

```powershell
docker build -t avito-orientation .
docker run --rm --network none --mount "type=bind,source=$($PWD.Path),target=/work" avito-orientation
```

На Linux во второй команде замените `source=$($PWD.Path)` на `source=$(pwd)`. Docker при первой сборке скачает и установит зависимости. После запуска в корне появится `submission.csv`. Замеры времени находятся в `results/executed.ipynb`. Для запуска нужен процессор x86-64 с AVX. Обучение и GPU не требуются.

Код решения — `main.ipynb`. Он запускается и без Docker, если установить зависимости из `requirements.txt` и выполнить все ячейки. Путь к тестовым данным можно задать переменной `AVITO_TEST_PATH`.

## Подход и проверка

Используется открытая модель PaddleOCR `PP-LCNet_x1_0_textline_ori`. Каждый кроп подаётся в модель дважды: как есть и после поворота на 180°. Две оценки объединяются в вероятность `p_180`. Веса загружаются из `models/`; внешние API во время предсказания не вызываются. Ручной разметки теста нет.

На Stepik эта быстрая версия получила **0,95944706**. На отдельной автоматически размеченной проверке из [HierText](https://github.com/google-research-datasets/hiertext) — **0,98424**. Эти выборки различаются, поэтому для оценки на задании ориентироваться следует на балл Stepik.

Также проверялся более медленный вариант: к классификатору добавлялось распознавание текста моделью PaddleOCR `eslav_PP-OCRv5_mobile_rec` для обоих поворотов *каждого* кропа. Он получил **0,98809114 на Stepik**. В текущий репозиторий вошёл быстрый вариант: он использует одну компактную модель и работает на CPU. Код и веса OCR-варианта в текущую версию не входят.

Использованы открытые [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR), [PaddlePaddle](https://github.com/PaddlePaddle/Paddle) и [HierText](https://github.com/google-research-datasets/hiertext). Версии библиотек указаны в `requirements.txt`.
